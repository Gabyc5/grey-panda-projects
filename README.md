## Projects and Coursework

Within this repository is a collection of my projects from various computer science courses and personal work. It includes:

- **Random Projects**: Independent coding projects ranging from small scripts to larger applications.
- **Coursework**: Coding assignments and exercises from courses like Operating Systems, Data Structures, and introductory programming classes, showcasing my development over time.

I also integrated Twilio for notifications, created database triggers, and set up hosting for the entire project.
  - [Link to Library Website Repo](https://github.com/Gabyc5/Team7-Library-Database.git)
  - [Link to Library Website](https://cougarchronicles.vercel.app/)
  - *Note: The MySQL database instance hosted on Azure has been turned off to avoid ongoing costs. As a result, some functionality that relies on the database may not be available.*
- **Volunteer Management Platform**: I contributed to both the front-end and back-end development of a scheduling platform that coordinated volunteer shifts across multiple campus organizations and events. On the front-end, I worked with JavaScript and React to build dynamic admin pages and create interactive “table” views for managing volunteers and events. On the back-end, I helped design and implement routes, middleware, and database interactions using MongoDB and Express.js. I also contributed to features like automated shift reminder notifications, report generation (PDF/CSV), and admin dashboard logic.
    - [Link to Volunteer Management Repo](https://github.com/sami5436/4353-Group11-SP25/tree/master)

Each folder corresponds to a specific project or class, providing a snapshot of the variety of skills and technologies I have worked with.
